# README and release media

These media were supplied by the project owner for the installation guide and
release. They are photos/video of a real Miyoo Mini Plus, not generated visuals.
The original recording and photograph remain unchanged on the owner's PC.

| File | Source | Treatment |
| --- | --- | --- |
| `first-launch.jpg` | `miyoo_on_device_compilation.jpg` | Original encoded photo and decoded pixels preserved. EXIF/XMP removed except the orientation needed to display it correctly. |
| `first-launch.gif` | `miyoo_vid_compile_and_run.mp4`, 00:00–00:08 | Preparation finishing at 100%. 240×426, 6 FPS, 96-color palette, normal speed, no audio. |
| `gameplay.gif` | Same recording, 00:42–01:00 | Gameplay only, from the first minute. 240×426, 8 FPS, 96-color palette, normal speed, no audio. |

The full first-minute sharing copy is a separate MP4: 720×1280, 30 FPS, H.264,
AAC audio, fast-start enabled. It retains the full 00:00–01:00 interval at normal
speed, including the preparation-to-game transition. Location and source-device
metadata are removed. Keep this larger upload file with release media rather
than the runtime ZIP or Git history.

The eight-second GIF shows the end of preparation, not its complete duration.
The measured fresh installation takes about 12 minutes; the GIF does not claim
an eight-second installation. GIF frame rates describe the recording export,
not measured game FPS.

Only these owner-supplied presentation captures are intended for public docs.
Original game assets, assemblies, packs, saves and other private QA captures
remain excluded from source control and the public runtime.
